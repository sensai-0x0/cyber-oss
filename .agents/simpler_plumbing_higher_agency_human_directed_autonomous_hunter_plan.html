Simpler Plumbing, Higher Agency: Human-Directed Autonomous Hunter Plan

Drop the gRPC boilerplate and rigid three-agent handoffs. Pair one lean Go sensor binary (tlsx + httpx + BadgerDB over MCP stdio) with one autonomous LangGraph investigator operating inside a human-authored mission.yaml autonomy envelope.

10 Files
1 Go sensor CLI + 1 LangGraph agent + 1 human policy file

1. Why simplifying the plumbing expands the agent's role

Multi-agent pipelines often waste engineering effort on rigid message passing between three separate LLM roles ("Clusterer -> Scorer -> Mitigator"). When you collapse those three into one capable generalist agent equipped with sharp tools and a clear human-written policy file, two things happen immediately:

  • Dynamic investigation: Instead of waiting passively on a one-way stream, the agent actively chooses which CIDR to sweep next, pivots from a suspicious CT cert in tlsx to a targeted httpx -favicon probe, and queries BadgerDB history on demand.
  • Human-directed autonomy: Rather than hardcoding thresholds in Python, the operator defines intent and blast-radius limits in mission.yaml. Within that envelope, the agent acts autonomously; at the boundary, LangGraph's interrupt() hands steering back to the human.

2. Complete directory structure

The entire codebase fits in 10 focused files—small enough for one engineer to read, test, and modify in an afternoon:

sentinel-lite/

    └── tests/

3. Human-directed autonomy via mission.yaml

Instead of burying rules in code, the human steers the agent through a declarative policy envelope:

mission: "Hunt newly staged C2/phishing infra in target ASNs before campaign launch"
targets: ["203.0.113.0/24", "198.51.100.0/24"]
watchlist_favicons: [-12948102]
autonomy:
  tier_1_autonomous: ["scan_cidr_delta", "probe_http_favicon", "query_kv_history"]
  tier_2_ttl_auto:   { action: "block_single_ip", max_ttl_minutes: 60, min_confidence: 0.90 }
  tier_3_interrupt:  ["block_cidr", "modify_rpz_wildcard", "pivot_new_asn"]
Autonomy Tier What the Agent Can Do Human Control Mechanism
Tier 1 · Free Choose CIDRs, run tlsx/httpx delta sweeps, query BadgerDB Bounded by targets allowlist & rate limit in Go
Tier 2 · Guarded Apply single-IP nftables/RPZ blocks at ≥0.90 confidence Mandatory max_ttl_minutes auto-expiry in BadgerDB
Tier 3 · Interrupt Block `/24` ranges, add wildcard RPZ rules, pivot to new ASNs LangGraph interrupt() pauses for operator approval

4. Full build & verification plan

  1. Build the Go MCP Sensor (`cmd/hunter`): Implement feistel.go, store.go, and runner.go exposing 4 MCP tools (scan_cidr_delta, probe_http_favicon, query_kv_history, apply_ttl_rule). Verify with go test -race ./... against a local mock TLS/HTTP server.
  2. Wire the Single LangGraph Loop (`agent/graph.py`): Connect the agent to mission.yaml and the Go MCP binary. The agent plans its own sweep order, investigates anomalies, and writes brief reasoning notes to graph state.
  3. Test Autonomy Boundaries (`agent/tests/test_autonomy.py`): Replay recorded JSONL deltas to prove Tier 1/2 actions execute autonomously with valid TTLs while Tier 3 actions reliably trigger interrupt() until resumed by the human.
