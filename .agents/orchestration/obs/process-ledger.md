# Process Ledger

Universal rules: [../../../CLAUDE.md](../../../CLAUDE.md). Written by the `conductor` skill at stage
REFLECT; read at stage ORIENT. Newest entries first. Dates as YYYY-MM-DD.

This file holds **habits**, not parameters. [constitution.md](../../evals/constitution.md) holds the
genes — numbers and model choices, mutated on a fitness score. This holds the reasoning patterns
that produced a bad allocation, which no gene value can express: a belief the conductor held at PATH
that turned out false at VERIFY, a step whose order matters, a signal it keeps missing.

An entry earns its place only if it would change a future allocation. "Be more careful" is not an
entry. Delete an entry once its lesson is enforced by a gene, a gate, or a line in the skill itself
— at that point it is code, and leaving it here is duplication.
